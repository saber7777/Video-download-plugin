# 模拟题：站址维修工单

这不是正式赛题。它只复现正式比赛的形状：同构全栈、三条规则、固定提交目录、一票否决。正式题面里的名词以当场试卷为准。

## 要求

在 90 分钟内完成一个单体系统。技术栈只用 Java Spring Boot、Vue 3、MySQL 8。

角色：

- 调度员：新建草稿、提交、派单、驳回、取消。
- 维修员：开始处理、办结。办结时填写备件用量。

状态只允许这些迁移：草稿到已提交或已取消；已提交到已派单、已驳回或已取消；已派单到处理中或已取消；处理中到已办结或已取消；已驳回回到草稿。已办结和已取消不能再变。

单号格式 `WX` 加 `yyyyMMdd` 加 6 位数字。并发新建不能重号。

两人同时派同一张单，只能成功一人，另一人看到冲突，单据仍只有一个维修员。备件数量不够时办结失败，工单状态和备件数量都不变。

未登录不能调用业务接口。演示账号写进 `data.sql`，密码保存哈希。

页面至少有登录、工单列表、新建、详情。按钮文字使用：登录、查询、新建、提交、派单、开始处理、办结、驳回、取消。

提交目录按 `pack/skills/submission/SKILL.md`。交卷前跑 `grade.py`。

## 做完后自己看的答案

合格实现使用 `biz_no_seq` 和 `LAST_INSERT_ID`，状态变更走动作接口，更新语句带版本条件，登录只放行一个接口。样例文件在 `fixtures/good`，那是闸门用的机制样本，不是完整工程。
